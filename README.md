# 만다라케 입고 알림
나카노점 공식 RSS를 300초 간격으로 확인하는 개인용 웹앱. 첫 정상 응답은 기준 목록으로 저장한다. 이후 상품 제목에 저장한 단어가 포함되면 발견 기록과 푸시 발송 대상을 SQLite에 함께 기록한다. RSS가 HTML이나 빈 목록을 반환하면 마지막 성공 시각을 보존하고 오류를 표시한다. 공식 피드의 현재 가용성과 게시 지연은 운영 환경에서 확인해야 한다.

### 실행
Python 3.10 이상에서 다음 명령을 실행한다. 키 파일은 최초 한 번 생성하고 백업한다.
```sh
python -m pip install -r requirements.txt
(umask 077 && python setup_keys.py > .env)
```
.env에 VAPID_SUBJECT=mailto:본인주소 를 추가하고 실제 이메일 주소를 입력한다. 아래 명령은 Linux/macOS 셸 기준이다.
```sh
set -a
. ./.env
set +a
python app.py
```
기본 포트는 8000이다. HTTPS 리버스 프록시 뒤에서 단일 프로세스로 실행하고 SQLite와 PEM 파일을 영구 디스크에 둔다. GitHub는 소스 저장소이며 수집과 구독 저장은 실행 중인 서버가 담당한다. 아이폰에서 HTTPS 주소를 Safari로 열어 홈 화면에 추가한 뒤 실행한다. 개인 접속 키를 입력하고 검색어 저장, 이 기기 알림 켜기를 차례로 누른다. 기기를 구독한 이후 발견된 상품부터 푸시를 받는다. URL별 최초 발견을 추적하며 가격 및 제조사 전용 필터는 이 버전에 포함되지 않는다.
